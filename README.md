# Crafting Planner

A vanilla-friendly Graveyard Keeper 1.407 mod project for planning multiple crafting/building goals and gathering exactly the materials still needed.

Core direction:

`pinned goals -> aggregate requirements -> player Have -> Missing -> Take Needed from the current storage`

The project is currently in the research/prototype stage. Production scope is intentionally narrow: no remote crafting, no automatic cross-storage logistics, and no dependency-expansion system unless those are approved later.
